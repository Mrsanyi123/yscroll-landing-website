# yscroll‑landing‑website

**A modern responsive landing page built with React, Vite, and Tailwind CSS.**

This repository contains a landing website template with y‑scroll animations designed for showcasing products, portfolios, or personal projects.

---

## 🚀 Features

✨ Built with **React + Vite** for fast development and production builds  
🎨 Style powered by **Tailwind CSS**  
📦 Uses modern libraries like **Supabase**, **Firebase**, **lodash**, and **React Router**  
🎉 Fun UI elements like confetti effects and scroll animations

---

yscroll‑landing‑website/

## 🛠️ Installation

These steps will get you a local copy up and running.

### 1. Clone the repo

2. Install dependencies

npm install

🚀 Running Locally

Start in development mode with:

npm run dev

Your landing page will be served at http://localhost:5173 (or another available port).

📦 Build for Production

Generate optimized production files:

npm run build

Preview a production build locally:
npm run preview
